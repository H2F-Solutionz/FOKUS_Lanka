## ✨ Key Features

### 🏛️ Premium Branding
- **Overlay Logo Identity**: High-impact navigation with a bold, overlapping brand asset.
- **Smart Filter System**: Dynamic logo color switching (White on Hero, Brand Colors on Scroll) for maximum elegance.
- **Blueprint Drafting Loader**: A custom-engineered loading experience that visualizes the technical drafting phase of construction.

### 🤖 Intelligent Assistant
- **AI-Driven Chatbot**: Trained on a custom knowledge base containing company history, services, and local Jaffna expertise.
- **Hybrid Logic**: Combines project-specific expert matching with free-tier AI conversational fallback.

### 🛠️ High-End UI/UX
- **Glassmorphic Design**: Modern, translucent interface elements using advanced Backdrop Blur.
- **Responsive Engineering**: Fully optimized for mobile, tablet, and desktop viewing.
- **Framer Motion Animations**: Smooth, high-performance transitions and interactive elements.

## 🚀 Tech Stack

- **Frontend**: React 19 + Vite

- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Hosting**: Cloudflare Pages (Serverless)
- **Backend Functions**: Cloudflare Pages Functions (Node.js/Workers)

## 🛠️ Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/H2F-Solutionz/FOKUS_Lanka.git
   cd fokus-lanka
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set up Environment Variables**:
   Create a `.env` file based on `.env.example`:
   ```bash
   cp .env.example .env
   ```

4. **Run development server**:
   ```bash
   npm run dev
   ```

## ☁️ Deployment

This project is optimized for **Cloudflare Pages**.

- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Root Directory**: `fokus-lanka`
- **Redirects**: Configured via `public/_redirects` for SPA routing.
